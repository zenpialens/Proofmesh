# Proofmesh
Universal Proof Layer for AI-Generated Content A trust layer that verifies the origin, authenticity, and modification history of AI-generated and human-generated content. 

Why it wins: AI provenance is a massive global challenge. Governments + companies are actively searching for solutions. Hedera’s low-cost, high-throughput consensus makes it ideal for proof anchoring.

What it does: Every piece of content (image, video, text) gets a Proof Stamp via Hedera Consensus Service. Tracks: Who generated it Which model Prompts Edits Full provenance chain Stores large files on IPFS; timestamps + hashes on Hedera. Use cases: Journalism verification Deepfake risk detection Traceable AI workflows Enterprise compliance
